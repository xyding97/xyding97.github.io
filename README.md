# Xiuyuan Ding personal website

This is the approved standalone v0.3 website, published directly as static HTML and CSS. No Jekyll installation or theme is required.

The four primary pages are `index.html`, `research/index.html`, `publications/index.html`, and `cv/index.html`. Shared styling is in `assets/css/site.css`. The portrait remains at its original image URL; the current CV remains at `files/CV.pdf`. Older public files and redirect pages are retained for URL compatibility.

Preview locally with `python3 -m http.server 8765`. The `.nojekyll` file tells GitHub Pages to serve these files directly. Preserve `CNAME`, canonical URLs, and redirects when editing.
